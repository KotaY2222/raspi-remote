# おうちリモコン (raspi-remote)

ラズベリーパイ上で動かし、スマホ・タブレットのブラウザから、エアコン・照明・テレビをまとめて操作するアプリ。
**赤外線の送信は今はダミー**で、画面とAPIの動作が確認できる段階。

## 動かし方
```bash
python3 server.py            # 既定は 0.0.0.0:8080
```
スマホやPCのブラウザで `http://<ラズパイのIPアドレス>:8080` を開く。標準ライブラリだけで動く(追加のインストール不要)。

- 外の気温・湿度は Open-Meteo から取得する。場所は環境変数 `WEATHER_LAT` `WEATHER_LON` `WEATHER_PLACE` で指定する(未指定は東京の仮の座標)
- 画面は iPhone の明暗設定に合わせて切り替わる。ホーム画面に追加して使える(PWA)

## 構成
| ファイル | 役割 |
| --- | --- |
| `server.py` | Web API と画面の配信、状態の保存、入力の検査 |
| `ir.py` | 赤外線の送信部。今は `DummyIR`(実際には送らず、送ったはずの内容を記録する)。実機が届いたら、ここだけ差し替える |
| `ai.py` | 話しかけた言葉を操作に変える(Claude API。キーが無いときは簡易解釈) |
| `static/` | スマホ向けの操作画面 |
| `docs/` | 使い方の資料 |
