# 話しかけて操作(AI連携)

画面の「話しかけて操作」の入力欄に、「暑いから冷房つけて」のように書くと、AIが操作に変えて実行します。
音声で使うときは、iPhoneのキーボードのマイクで入力します(アプリ側に音声認識は付けていません)。

## 2つのモード
| モード | 条件 | できること |
| --- | --- | --- |
| AIで解釈 | `ANTHROPIC_API_KEY` が設定され、`anthropic` が入っている | 言い換えや複数の操作を理解する。外の気温も参考にする。曖昧なら聞き返す |
| 簡易解釈 | 上の条件を満たさない/AIにつながらない/1日の上限に達した | 決まった言い回し(冷房・暖房・消して・おやすみ など)だけ。デモ用 |

画面の「話しかけて操作」の下に、いまのモードが出ます。

## AIで解釈を使うには(ラズパイ / PC)
1. SDKを入れる
   ```bash
   pip install anthropic
   ```
2. **自分のターミナルで**APIキーを環境変数に設定してから起動する(キーをファイルやチャットに書かない)
   ```bash
   export ANTHROPIC_API_KEY="(自分のキー)"
   python3 server.py
   ```
   常時起動にする場合は、systemd の `EnvironmentFile` に別ファイルで置き、そのファイルを自分だけが読める権限にする。
3. 任意の設定(環境変数)
   - `AI_MODEL`: 既定は `claude-opus-5-5`。安く速くするなら `claude-haiku-5-5`
   - `AI_DAILY_LIMIT`: 1日のAI利用回数の上限。既定は50回。超えると簡易解釈に切り替わる

## 安全のための作り
- AIの返答は「案」として扱い、サーバーが全部検査してから実行する(温度は16〜30℃など)。1つでも不正なら何も送らない
- AIが使えるのは、エアコン・照明・テレビの操作とシーンだけ
- 画面に出す実行結果は、AIの文章ではなく、実際に実行した内容
- 発話・解釈・実行結果を `data/ai_log.jsonl` に1行ずつ記録する(誤動作の確認用。発話の内容が残る)

## 注意
- **外部への送信:** AIで解釈するとき、発話、各機器の現在の設定(推定)、外の気温・湿度が Anthropic のAPIに送られる。簡易解釈では何も送らない
- **費用:** 呼び出し1回ごとに料金がかかる。1回あたり1円前後の見込みだが、実測していない概算。上限は `AI_DAILY_LIMIT` で抑える
- **認証がない:** 同じネットワークの端末なら誰でも入力できる。上限回数はその歯止めでもある(簡易PIN認証は要件書で任意の扱い)
- **検証の範囲:** AIの返答を模擬した自動テストと、簡易解釈の画面確認までを行った。**本物のClaude APIへの接続は、キーが無いため未確認**
- 赤外線の送信は、いまもダミー
